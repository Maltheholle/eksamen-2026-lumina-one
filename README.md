# LUMINA AUDIO LANDINGPAGE-Case



### Beskrivelse af projekt:


Projektet består af et redesign af landingpagen for LUMINA One med fokus på forbedret UX, UI og frontend-konstruktion. Løsningen er udviklet i HTML, CSS og JavaScript og indeholder blandt andet interaktive elementer som farvevælger, animationer og sliders. Brugeren kan udforske produktets funktioner, farvevarianter og anmeldelser gennem en dynamisk og visuelt orienteret brugeroplevelse.

### Fil- og mappestruktur:
For mere overskuelig image-struktur, har jeg valgt at dele mapperne op i forskellige mapper hhv. body.img, hero-section.img, icons.img og trust-pilot-cards.img

### Validering af CSS:
![CSS-validation.](/readme.img/css-validator "CSS-Validation.")

Her var en række ensartede fejl, som gik på at der var brugt letter-spacing med % i stedet for px, eller rem osv. Så det er rettet.
Siden er valideret med w3schools css-validator


### Validering af HTML:
![HTML-validation.](/readme.img/html-validation "HTML-Validation.")
Her var de eneste errors, at der få steder ikke var en "alt" beskrivelse til img-tags. På billedet er der søgt på siden efter ordet "error" så det er tydeligt, at der ikke gemmer sig nogle længere nede.

### JavaScript datastruktur:

Projektet arbejder primært med DOM-elementer hentet via querySelector() og querySelectorAll(). Elementerne gemmes i variabler og arrays, som bruges til at styre interaktioner, animationer og dynamisk indhold på siden.

Derudover anvendes forEach() til at gennemløbe elementer og udføre handlinger på hvert element individuelt.

Datastrukturen passer godt til projektet, da løsningen bygger på manipulation af eksisterende HTML-elementer.
